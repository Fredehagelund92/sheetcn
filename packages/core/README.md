# @sheetcn/core

The headless core of [sheetcn](https://github.com/Fredehagelund92/sheetcn): column schema, cell values (parse, format, validate) and a row store with transactions and undo. Plain TypeScript with no React, DOM or TanStack dependency.

Early work, not yet published. See the [repository README](https://github.com/Fredehagelund92/sheetcn#readme) for status and API notes.
