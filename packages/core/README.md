# @sheetcn/core

The headless core of [sheetcn](https://github.com/Fredehagelund92/sheetcn): column schema, 14 column types and a registry for your own, cell values (parse, format, validate, compare, filter), views that filter, sort and group rows, a row store with transactions and undo, selection geometry, the keyboard map and the column fill math. Plain TypeScript with no React, DOM or TanStack dependency.

`@sheetcn/core/phone` is an optional entry for phone numbers, which needs `libphonenumber-js` 1.13.15 installed alongside.

Early work, not yet published. See the [repository README](https://github.com/Fredehagelund92/sheetcn#readme) for status and API notes.
