# @sheetcn/react

The React binding of [sheetcn](https://github.com/Fredehagelund92/sheetcn): `useSheet` wires the [`@sheetcn/core`](../core) store to TanStack Table cell selection and TanStack Virtual, with the keyboard map, editing state, pointer selection, focus, and fixed or fill column sizing with fit to content. It renders nothing; the grid markup and styles come from the shadcn registry.

Early work, not yet published. See the [repository README](https://github.com/Fredehagelund92/sheetcn#readme) for status and API notes.
