# sheetcn

A customizable spreadsheet-like component and data table for React and shadcn/ui.

Status: a spike. The first goal is to measure cell range selection with virtualization at 100,000 rows and to decide how much of the editing core to build.

Planned: one headless core (selection, editing, clipboard, history, import) with shadcn styled views, in two presets (`table` and `sheet`), installable from a shadcn registry. MIT licensed.
